      How to check a board

      1. 1Board TX → adapter RX. The three holes are on the board's underside next to the USB-C, labelled RX / TX / GND. Use a 3.3 V USB-TTL adapter.
      2. 2Board GND → adapter GND.
      3. 3Board RX → adapter TX (optional: lets the tool log in and read the cpu_id of a board that boots).
      4. 4Pull the board's power and plug it back in. A normal boot, not maskrom: don't hold any button. The RAM verdict appears within a few seconds.

      Wiring help
      Underside of the R76S, next to the USB-C: three holes labelled RX / TX / GND, 3.3 V, 1500000 baud.
      board TX → adapter RX and GND → GND: the boot log (needed).
      board RX → adapter TX: lets the tool log in to a board that boots and read its cpu_id (optional).
      Nothing at all after a power-cycle? Swap TX and RX, check GND, and make sure nobody is holding MASKROM.
